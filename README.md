# payments-dashboard

Evaluation project: a payments list screen for a fintech dashboard, with sorting, pagination and filters over mock data. Not affiliated with any payment provider. All data is fake.

- Spec: `docs/spec.md`
- Agent instructions: `CLAUDE.md`

## Run
```bash
npm install
npm run dev
```

## Tests
```bash
npm test
npx tsc --noEmit
npm run lint
```

## Mock data
```bash
npm run generate:data
```
